# ICPC Sohar University Club — website

Vite + React + TypeScript + Tailwind CSS + Framer Motion. Bilingual (Arabic RTL default / English).

```bash
npm install
npm run dev        # http://localhost:5173/ICPCSU/
npm run build      # production build → dist/
npm run preview    # serve the build locally
```

- Content editing: see **CONTENT_GUIDE.md**.
- Deploy: push to `main`; `.github/workflows/deploy.yml` builds and publishes to GitHub Pages
  (repo Settings → Pages → Source: **GitHub Actions**). Site URL: `https://hasanalmamari79.github.io/ICPCSU/`.
